# survey-tally

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표(문항 / 유효 응답 / 평균 / 빈 응답 / 제외)를 보여 주는
`index.html` 한 파일짜리 설문 집계기입니다.

- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않습니다.
- 붙여넣은 데이터는 브라우저 안에서만 계산하며, 보내거나 저장하지 않습니다(CSP로 외부 연결도 막음).

## 쓰는 법
`index.html`을 브라우저로 열거나 GitHub Pages로 배포한 뒤, 엑셀에서 머리글을 포함한 범위를 복사해 붙여넣습니다.
붙여넣으면 바로 집계되고, `집계` 버튼이나 Ctrl/⌘+Enter로 다시 집계할 수 있습니다.

## 집계 규칙
- 첫 열(응답번호)은 집계하지 않습니다.
- 앞뒤 공백을 지운 값이 `1`~`5`면 유효, 비었거나 공백만 있으면 빈 응답, 그 밖의 값은 제외.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다.
- 평균 = 유효 응답의 합 ÷ 유효 응답 수, 소수 셋째 자리에서 반올림해 둘째 자리까지. 유효가 0이면 `-`.

세부 결정은 [docs/PLAN.md](docs/PLAN.md)에 있습니다.

## 시험
의존성 설치 없이 Node 22 이상에서:

```bash
npm test
```

시험은 `index.html` 안의 `<script id="tally-core">`(계산 로직)를 그대로 뽑아 실행합니다.
