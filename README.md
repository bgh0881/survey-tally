# 10x10 삼목

10x10 판에서 흑과 백이 번갈아 돌을 놓고, 가로·세로·대각선으로 같은 색 3개를 먼저 잇는 쪽이 이기는 게임입니다.
`index.html` 한 파일로 동작하며 외부 라이브러리나 네트워크 연결이 없습니다.

## 하는 법
`index.html`을 브라우저로 엽니다. 한 기기에서 두 사람이 번갈아 둡니다.

- 흑이 먼저 둡니다.
- 3개 이상 이어지면 승리하고, 이긴 줄이 표시됩니다. 판이 가득 찰 때까지 승부가 안 나면 무승부입니다.
- `무르기`로 마지막 한 수를 되돌리고, `새 게임`으로 처음부터 다시 합니다.
- 키보드: 방향키로 이동, Enter·Space로 착수.

## 시험
의존성 설치 없이 Node 22 이상에서:

```bash
npm test
```

시험은 `index.html` 안의 `<script id="game-core">`(게임 규칙)를 그대로 뽑아 실행합니다.
